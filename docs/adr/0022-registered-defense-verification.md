# ADR 0022 · Verify the registered defense on a separate target

The first release uses the built-in target and a reviewed policy change. A text recommendation alone cannot show that the policy is active. Applying the preset to the selected chat would also change the baseline. Resolve a separate candidate configuration and inspect both manifests. Run the direct probes on the candidate, then compare independent ordinary banking runs with the existing receipt checks.

Store the completed result in the existing assessment report. This preserves cancellation, ownership and report export without adding a second job type. Capability evidence, the likely cause, the recommendation and verification each carry their own meaning. A capability finding records available authority. A successful verification covers the stated tests and candidate configuration.
