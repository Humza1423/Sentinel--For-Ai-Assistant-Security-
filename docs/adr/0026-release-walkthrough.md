# T16A · Exercise the visible release path

Unit tests can substitute an API response, so a green frontend suite alone cannot establish that the browser and database agree. One opt-in Playwright walkthrough exercises the existing app through its normal controls, checks both scope evidence IDs and compares the export with the saved report. It uses a fresh browser context and the local fixture configuration. This adds one development dependency and no production service.

The [demo guide](../DEMO.md) doubles as a learning note: playback explains a known incident, while a new assessment measures the configured assistant. Keeping this distinction visible lets an engineer explain exactly what was verified.
