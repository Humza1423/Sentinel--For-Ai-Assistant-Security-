# T16B · Give examples and real checks distinct entry points

The banking workspace previously used “Assess assistant” to open a saved example. From there, engineers had to find a second route to start an assessment. Keeping two visible actions on the same page lets a beginner watch the example or proceed directly to the selected assistant's checks. A guided wizard would add steps for engineers who already know the workflow.

The report leads with the saved verdict and the results behind it. The activity log stays collapsed until someone wants to see how an answer or check ran. The privacy report compares the current assistant with a separate configuration using the registered rule. The example describes a prior fixture and has its own playback controls. The [walkthrough](../DEMO.md) follows both paths.
